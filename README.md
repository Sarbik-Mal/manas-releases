# Manas

Manas is a terminal AI agent for Windows that works with the AI provider of your choice.

This repository only holds downloads. Get the latest installer from the Releases page:

https://github.com/Sarbik-Mal/manas-releases/releases/latest

Download `manas-setup.exe` and double-click it.

Manas is beta software. You are asked to accept the license terms during installation.
